# WaterIO
### ZADBAJ O SWOJE NAWODNIENIE!
WaterIO jest aplikacją mobilną na Androida, która pomaga użytkownikom dbać o regularne nawodnienie organizmu. Projekt został stworzony z naciskiem na wygodę użytkownika, architekturę offline-first oraz powiadomienia push.
Aplikacja jest dostępna dla Ciebie gdzie tylko chcesz, abyś nigdy nie zapomniał o piciu wody!

##  Główne funkcjonalności

* **Szybkie dodawanie wody:** Wygodne przyciski do dodawania zdefiniowanych porcji oraz możliwość wpisania niestandardowej ilości.
* **Wizualizacja postępów:** Dynamiczny, okrągły pasek postępu pokazujący stopień realizacji dziennego celu na ekranie głównym.
* **Obliczanie passy:** System motywacyjny śledzący, ile dni z rzędu użytkownik osiągnął swój dzienny cel nawodnienia.
* **Zarządzanie historią:** Czytelny podgląd historii wpisów z podziałem na daty oraz opcją szybkiego usuwania błędnych logów.
* **Personalizacja:** Możliwość ustawienia własnego, dziennego celu nawodnienia z poziomu profilu użytkownika.
* **Architektura Offline-First:** Aplikacja działa płynnie bez dostępu do internetu, zapisując dane lokalnie i synchronizując je z chmurą w tle po odzyskaniu połączenia.

## Technologie

* **Język programowania:** Kotlin
* **Serwer backend:** render.com
* **Lokalny zapis danych:** Room Database
